Nach Division durch a
Ausdruck unter der Wurzel

Die pq-Formel benötigt zuerst den Leitkoeffizienten 1: Teile ax² + bx + c = 0 durch a. Dann gilt p = b/a und q = c/a. Die Teilung verändert die Lösungen nicht, solange a ≠ 0.

Wurzelausdruck > 0

Zwei verschiedene reelle Nullstellen.

Wurzelausdruck = 0

Eine doppelte reelle Nullstelle.

Wurzelausdruck < 0

Keine reellen Nullstellen.
